# Figures

Figures used in public technical releases should be stored here or in version-specific subdirectories.

## Figure types

- system architecture and layer diagrams;
- exterior rib/fin geometry diagrams;
- apparel concept previews;
- heat-spreader topology diagrams;
- simulation plots;
- experimental apparatus and measurement-location diagrams;
- measured performance plots.

## Publication rule

Every quantitative figure should identify whether the data are:

- **SIMULATION**;
- **MEASUREMENT**;
- **SCHEMATIC / NOT TO SCALE**.

Do not place simulated performance next to a product rendering without a visible label that prevents the rendering from being interpreted as a tested product.

For stable releases, retain source data or source code sufficient to regenerate quantitative figures.
